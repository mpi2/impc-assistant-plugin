# IMPC Assistant

This package contains six IMPC skills and four hosted MCP connections.
Install it using the marketplace instructions in the repository's top-level README.
For a standalone copy, use the host's supported portable-plugin loading workflow.

Start with: "Use IMPC Assistant to find cornea opacity IMPReSS parameter pages."

Python workflows require shell access, uv, and impc-api. Keep generated files in
an external working folder. The host supplies the agent/model; no custom agent
runtime is bundled. MCP aliases differ by host, so skills discover actual tools.

This package has no credentials or automatic installer. Local installation does
not publish it to an account or public directory. Preserve LICENSE and skill notices.
